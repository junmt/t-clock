# t-clock 仕様書

常に最前面に表示され、邪魔にならずに時刻を確認でき、タイマーで予定に遅れないようにするための Windows 向け常駐時計アプリ。

- ステータス: ドラフト v0.1
- 対象OS: Windows 10 / 11 (64bit)
- 技術スタック: C# / WPF (.NET 8) — Windows 専用ネイティブ（NuGet 依存ゼロ）

---

## 1. 目的とコンセプト

- **常に時間が見える**: 作業を邪魔せず、画面の隅で常に現在時刻を確認できる。
- **遅れない**: タイマー/アラームをセットし、指定時刻・指定時間の経過を確実に通知する。
- **軽量・常駐**: 低メモリ・低負荷で PC 起動中つけっぱなしにできる。

### 想定ユーザーシナリオ
- 会議やタスクの開始5分前にタイマーをセットし、集中していても遅れずに気づける。
- 常に画面隅の小さな時計で現在時刻を把握し、時計を見るために視線や手を大きく動かさない。

---

## 2. 機能要件

### 2.1 時計表示（常時）
- 現在時刻を **HH:MM:SS**（秒表示のON/OFF切替可）で表示する。
- 日付表示（YYYY/MM/DD (曜日)）のON/OFF切替。
- 12時間 / 24時間表示の切替。
- 1秒ごとに更新（秒非表示時は分単位更新でも可）。

### 2.2 常に最前面表示（Always on Top）
- ウィンドウを常に他アプリより前面に表示する。
- 最前面表示のON/OFFをトグルできる。
- フルスクリーンアプリ（ゲーム等）上での挙動は「ベストエフォート」とする（OS制約により前面に出ない場合がある）。

### 2.3 邪魔にならない表示（Unobtrusive UI）
- **フレームレス**: タイトルバー・枠のない小型ウィンドウ。
- **半透明**: ウィンドウ全体の不透明度を 20%〜100% で調整可能。
- **クリックスルー（マウス透過）**: ONにすると時計を貫通して背後のアプリを操作できる（トグル）。
- **ドラッグ移動**: ウィンドウ本体をドラッグして任意の位置へ移動。
- **スナップ**: 画面四隅への吸着（任意機能）。
- **コンパクト/通常モード**: 最小サイズの時計のみ表示と、操作UIを含む通常表示を切替。

### 2.4 タイマー機能
- **カウントダウンタイマー**: 分・秒（または時:分:秒）を指定して開始。残り時間を表示。
- **アラーム（指定時刻）**: 指定した時刻（例 14:30）に通知。
- **クイックタイマー**: 1分 / 3分 / 5分 / 10分 / 15分 などのプリセットボタン。
- 複数タイマーの同時セット（最低3件）。
- タイマーごとにラベル（名前）を付けられる。
- 一時停止 / 再開 / リセット / 削除。
- 実行中タイマーの残り時間を時計と並べて表示。

### 2.5 通知（タイマー/アラーム発火時）
以下を組み合わせて通知する（各ON/OFF設定可）:
- **Windows トースト通知**: OS標準の通知バナーにラベルと時刻を表示。
- **画面フラッシュ/点滅**: 時計ウィンドウ（またはオーバーレイ）を点滅・色変化させて視覚的に強調。終了時は最前面へポップして目立たせる。
- スヌーズ（例: 5分後に再通知）に対応。
- 通知は確認（クリック/ボタン）するまで一定間隔で繰り返す設定を持てる。

### 2.6 設定の永続化
- 表示設定・ウィンドウ位置・不透明度・最前面ON/OFF・タイマー通知方法などを保存し、次回起動時に復元する。
- 設定は JSON ファイルでローカル保存（`%APPDATA%/t-clock/settings.json`）。

### 2.7 起動・常駐
- **システムトレイ常駐**: 閉じるボタンでトレイに格納、トレイアイコンから復帰/終了。
- **自動起動**: Windows スタートアップ時に自動起動するオプション。

## 3. 非機能要件

| 項目 | 要件 |
|------|------|
| メモリ | 常駐時 目安 100MB 未満 |
| CPU | アイドル時ほぼ 0%（1秒更新の描画のみ） |
| 起動時間 | 2秒以内 |
| 時刻精度 | OSのシステム時刻に同期、ドリフトなし |
| 配布 | 単一 `.exe`（self-contained publish、ランタイム同梱・利用者はインストール不要） |

## 4. 技術方針（実装セクション）

### 4.1 スタック
- **C# / WPF (.NET 8, `net8.0-windows`)**: Windows ネイティブ。追加ツールチェーンは .NET SDK のみ。
- **NuGet 依存ゼロ**: WPF（UI）+ WindowsForms（`NotifyIcon` トレイ）+ `System.Text.Json`（設定）はすべて .NET 同梱。
- コードビハインド中心のシンプル構成（`MainWindow.xaml(.cs)` に UI と制御を集約）。

### 4.2 各機能の実装手段
- **フレームレス/透過**: `WindowStyle=None` + `AllowsTransparency=True` + `Background=Transparent` + 角丸 `Border`。
- **最前面**: `Window.Topmost`。
- **不透明度**: `Window.Opacity`（20〜100%）。
- **クリックスルー**: Win32 `SetWindowLong(GWL_EXSTYLE, WS_EX_TRANSPARENT|WS_EX_LAYERED)` を P/Invoke で切替。
- **ドラッグ移動**: `Window.DragMove()`（操作コントロール上では無効化）。
- **トレイ**: `System.Windows.Forms.NotifyIcon` + `ContextMenuStrip`（表示 / クリックスルー切替 / 終了）。
- **通知**: `NotifyIcon.ShowBalloonTip`（トースト風バナー）+ 画面フラッシュ（`DoubleAnimation` でオーバーレイ点滅）。
- **自動起動**: レジストリ `HKCU\...\CurrentVersion\Run` に exe パスを登録/削除。
- **設定保存**: `%APPDATA%\t-clock\settings.json`（`System.Text.Json`）。

### 4.3 タイマー実装方針
- `DispatcherTimer`（250ms）で全タイマーを一括評価。各タイマーは「終了予定の絶対時刻 `EndAt`」を保持。
- 残り時間は毎tick `EndAt - 現在時刻` で算出するため、スリープ復帰やUIの間引きがあってもズレない。
- `EndAt` 到達で状態を Done にし、トースト + 画面フラッシュ + 最前面ポップを実行。
- 一時停止は残り時間を保存、再開時に `EndAt = 現在時刻 + 残り` を再計算。

## 5. UI 構成（案）

```
┌──────────────────────┐
│   14:30:05           │  ← 大きな時計（常時表示）
│   2026/07/05 (Sun)   │  ← 日付（任意）
├──────────────────────┤
│ ⏱ 会議  02:45 [⏸][×] │  ← 実行中タイマー
│ [+1m][+3m][+5m][+10m]│  ← クイックタイマー
│ [⚙設定] [📌最前面]    │
└──────────────────────┘
```
- コンパクトモードでは時計行のみ表示。
- ホバー時のみ操作ボタンを表示する等で「邪魔にならない」を実現。

## 6. 設定項目一覧

| カテゴリ | 項目 | 既定値 |
|----------|------|--------|
| 時計 | 秒表示 | ON |
| 時計 | 日付表示 | ON |
| 時計 | 12/24時間 | 24時間 |
| 表示 | 最前面 | ON |
| 表示 | 不透明度 | 90% |

| 通知 | 画面フラッシュ | ON |

| 起動 | 自動起動 | OFF |
| 起動 | トレイ常駐 | ON |

## 7. スコープ外（今回は対象としない）

- マルチOS対応（macOS / Linux）— WPF は Windows 専用。本仕様では Windows のみを対象とする。
- クラウド同期 / アカウント機能。
- ポモドーロ等の高度なタイム管理機能（将来の拡張候補）。
- ウィジェット的なカレンダー連携。
